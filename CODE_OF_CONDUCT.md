# Code of Conduct

Participants are expected to be respectful, constructive, and inclusive. Harassment, discrimination, personal attacks, and deliberately disruptive behavior are not welcome.

Report unacceptable behavior privately to the maintainer at [quonainejaz-official@users.noreply.github.com](mailto:quonainejaz-official@users.noreply.github.com). Reports will be reviewed confidentially where possible.
