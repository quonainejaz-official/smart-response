# Getting started

SmartResponse standardizes the response contract around an existing controller or application operation. It does not own routing, authentication, validation, persistence, or protocol servers.

Choose the smallest integration that fits:

1. Use `Core\\SmartResponse` in plain PHP or another framework.
2. Use `HasSmartResponse` or the Laravel facade in Laravel controllers.
3. Select `json`, `xml`, `legacy`, `graphql`, or `soap` explicitly when automatic request detection is not enough.

Continue with [installation](installation.md) and [basic usage](basic-usage.md).
